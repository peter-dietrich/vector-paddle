# Vector Paddle — macOS Help

Classic paddle tennis and modern 3D table tennis

## How to play

Classic is Pong-style paddle tennis; Modern is a behind-the-paddle 3D table-tennis match. Choose your game mode, difficulty and player configuration within the game.

## Controls

| Control | Action |
|---|---|
| Classic: W/S, Up/Down | Move the two paddles. |
| Classic: Return / Space | Start or serve. |
| Modern: mouse pointer, A/D | Move the near-side paddle and aim. |
| Modern: click, Return, B | Return a ball after it bounces. |
| Modern: 1 / 2 / 3 | Drive / Backspin / Smash. |
| Modern: Space | Serve when your turn. |
| P | Pause or resume. |
| R | New match. |

## Records and saving

Classic and Modern each have separate high scores and saved match slots. Settings and checkpoints are local to your Mac; Modern saved matches restore paused.

## Mac menus

Select **Game → How to Play**, **Controls & Shortcuts** or **Scores & Saving**. The Help menu opens the built-in offline manual. Existing gameplay shortcuts are unchanged.
